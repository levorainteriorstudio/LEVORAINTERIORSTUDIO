Add a portfolio project

Prepare the image and project data files here. Then upload both files to your GitHub repository to publish the new project.

Important: This GitHub Pages website is static. This tool prepares the files; it does not publish directly to GitHub or store uploads online.

After downloading:
  1. Put the downloaded image inside assets/projects/.
  2. Upload the new projects.json to the repository root, replacing the old one.
  3. Wait for GitHub Pages to publish the update.
